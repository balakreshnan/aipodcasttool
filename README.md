# PodCast Studio

A web-based podcast studio concept for recording remote video conversations, editing multi-track sessions, and publishing directly to YouTube with real-time AI support.

## Quick start

You can preview the UI in two ways:

### Option 1: Open directly

Open `index.html` in your browser. Some browsers restrict local file access to fonts/scripts or camera access, so if the page looks incomplete or recording fails, use the server option below.

### Option 2: Run a local web server

From the project root:

```bash
python -m http.server 8000
```

Then visit (recording requires HTTPS or `localhost`):

```
http://localhost:8000/index.html
```
